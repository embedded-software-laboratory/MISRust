\paragraph{Rule 15.1.1}
\begin{longtable}{p{13cm}}
\textbf{Analysis Result} \\
(C3) Rule can be dropped completely \\
\end{longtable}
\textbf{Comment:} Rust object construction and destruction is done differently. For construction, typically an associated function (per convention named new) without self (or this) reference is used, to return a value of the type being constructed. The problem addressed by this rule does not occur. Destruction requires implementation of the Drop trait, which has no access to a dynamic trait implementation and is called automatically. \\
