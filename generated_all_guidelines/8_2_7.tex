\textbf{Comment:} Interpreting a pointer type as integer will yield that pointer's address in Rust. Accessing a pointer has to be handled in an \texttt{unsafe} block (`Rust Reference: Type cast expressions p. 205/432'). The rationale of the rule still holds in \texttt{unsafe} context. However, such casts have to reside within \texttt{unsafe} blocks, providing developers a strong indication that they have to pay extra attention for the contained code. \\
